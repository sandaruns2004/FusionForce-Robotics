# Level 2 — STM32 Firmware
## STM32F411CEU6 HAL, Peripherals, and PCA9685 Driver

## Why This Level Matters
RUNNER-4 has no operating system. Every sensor read, servo write, and timing decision is your firmware. Understanding HAL deeply prevents race conditions, I2C hangs, and ADC glitches under competition pressure.

## Topics

### 1. STM32F411CEU6 Architecture
```
Core:    ARM Cortex-M4F, 100MHz
Flash:   512 KB (code + calibration data in last sector)
RAM:     128 KB (stack, DMA buffers, gait arrays)
FPU:     Single-precision hardware float (atan2f, sinf = 1 cycle)
AHB:     DMA1/DMA2 for ADC + UART + SPI
APB1:    I2C1, I2C2, TIM2, TIM3, TIM4
APB2:    ADC1, USART1, TIM1
```

### 2. HAL I2C — PCA9685, MPU6050, VL53L0X, TCS34725

```c
/* I2C1 initialization (PB6=SCL, PB7=SDA, 400kHz) */
/* Generated by CubeMX, add this in USER CODE */

/* Write one register: */
uint8_t buf[2] = {reg_addr, value};
HAL_I2C_Master_Transmit(&hi2c1, device_addr << 1, buf, 2, HAL_MAX_DELAY);

/* Read one register: */
HAL_I2C_Master_Transmit(&hi2c1, device_addr << 1, &reg_addr, 1, 100);
HAL_I2C_Master_Receive (&hi2c1, device_addr << 1, &value, 1, 100);

/* Common mistake: HAL uses 8-bit address (7-bit addr << 1)
   PCA9685 address: 0x40 -> pass 0x80 to HAL */
```

**Device addresses (8-bit HAL format):**

| Device | 7-bit addr | HAL 8-bit | Bus |
|--------|-----------|-----------|-----|
| PCA9685 | 0x40 | 0x80 | I2C1 |
| MPU6050 | 0x68 | 0xD0 | I2C1 |
| TCS34725 | 0x29 | 0x52 | I2C1 |
| VL53L0X Front | 0x30 | 0x60 | I2C2 |
| VL53L0X Left | 0x31 | 0x62 | I2C2 |
| VL53L0X Right | 0x32 | 0x64 | I2C2 |

### 3. PCA9685 PWM Driver

```c
/* Key registers */
#define PCA9685_MODE1    0x00   /* 0x20 = auto-increment, 0x10 = sleep */
#define PCA9685_PRESCALE 0xFE   /* Set frequency */
#define LED0_ON_L        0x06   /* CH0 base, each channel = +4 bytes */

/* Prescaler for 50Hz: round(25MHz / (4096 * 50)) - 1 = 121 */

/* Set PWM for one channel: */
void PCA9685_SetPWM(uint8_t ch, uint16_t on, uint16_t off) {
    uint8_t reg = LED0_ON_L + ch * 4;
    uint8_t buf[5] = {reg,
        on & 0xFF, on >> 8,
        off & 0xFF, off >> 8};
    HAL_I2C_Master_Transmit(&hi2c1, 0x80, buf, 5, HAL_MAX_DELAY);
}

/* Servo angle to tick (50Hz, MG90S): */
/* tick = 102 + (angle/180.0) * 389 */
/* 0° = 102 (500µs)   90° = 307 (1500µs)   180° = 491 (2400µs) */
```

### 4. ADC1 + DMA1 — 9-Channel IR Line Array

```c
/* CubeMX: ADC1, IN0-IN8 (PA0-PA7, PB0), DMA1 Stream0 Ch0, circular */
/* Each channel oversampled 16× in software for noise rejection */

#define LA_NUM_SENSORS  9
#define LA_OVERSAMPLE   16
#define LA_BUF_SIZE     (9 * 16)   /* 144 words */

volatile uint32_t adc_dma_buf[LA_BUF_SIZE];

void LA_Init(void) {
    HAL_ADC_Start_DMA(&hadc1, (uint32_t*)adc_dma_buf, LA_BUF_SIZE);
}

/* In 50Hz update loop — raw = average of 16 samples per sensor */
uint32_t raw = 0;
for (int k = 0; k < 16; k++)
    raw += adc_dma_buf[sensor_i * 16 + k];
raw /= 16;
```

### 5. Timer Interrupts (TIM2 + TIM3)

```c
/* TIM2: 20ms period -> 50Hz main loop trigger */
/* TIM3: 10ms period -> 100Hz IMU update */

volatile uint8_t update_flag = 0;

void HAL_TIM_PeriodElapsedCallback(TIM_HandleTypeDef *htim) {
    if (htim->Instance == TIM2) {
        update_flag = 1;    /* Signals main loop to run */
    }
    if (htim->Instance == TIM3) {
        MPU6050_Update(&himu);   /* 100Hz IMU complementary filter */
    }
}

/* In main() while loop: */
void App_Run(void) {
    if (!update_flag) return;   /* Exit if not yet 20ms */
    update_flag = 0;
    /* ... sensor reads, state machine, gait, IK, servo write ... */
}
```

## Practical Exercises

1. **PCA9685 sweep test**: Make CH0 sweep 0° → 180° → 0° in a loop. Verify with oscilloscope: pulse width 500µs at 0°, 1500µs at 90°, 2400µs at 180°.
2. **I2C scan**: Write a program that tries all 127 addresses and prints the ones that ACK. Should find: 0x40, 0x68, 0x29 on I2C1; 0x30, 0x31, 0x32 on I2C2 (after VL53L0X remap).
3. **ADC DMA test**: Start ADC1 DMA, print all 9 sensor raw values via UART every 500ms. Cover sensors with hand → values change.
4. **50Hz timer test**: Toggle PC13 LED in TIM2 callback. Count toggles/second with a phone stopwatch → should be exactly 50.

## Prerequisite for Level 3
- Can configure PCA9685 and sweep all 15 servo channels via UART commands
- Can read and print all 9 ADC line sensor values
- Can read MPU6050 raw accel + gyro over I2C1
- Can read all 3 VL53L0X distances over I2C2
- TIM2 50Hz interrupt triggers main loop correctly
